# Generated C representation inspection

Inspected the locked C emitter output from the complete core build on 2026-11-07; no generated C was edited. `tools/core/layout.py` records complete function excerpts, line numbers and C hashes for each fresh build. The final summary rejects a missing, stale or changed layout record. This inspection establishes representation, not a measured RSS ceiling or a proof of compiler correctness.

- `roundtrip.c`, `core_scalars_created`: the budget is flattened into 20 U32 fields. A scalar chunk has one U32 block at result slot 21 and a second U32 width-metadata block at slot 29, each with the checked power-of-two depth. Result slots 22–28 preserve logical size, capacity, source identity and live-allocation token. The data block is zero-filled and the metadata block is one-filled.
- `core_scalars_drop` sinks the width block, then delegates to `core_storage_drop`, which sinks the value block before returning the allocation charge. Both arrays therefore participate in the same owner lifetime. Emitted `blk_read`/`blk_write` use U32 cells for these non-ARR blocks; `blk_at` masks indices, confirming that source-level logical range checks remain necessary.
- `sha.c`, `hash_sha256_initialized`: eight explicit U32 initial chaining words, a single `blk_new(...,6ull,...)` U32 block (64 words), pending count and high/low length limbs, plus a three-field allocation token. The pending input bytes occupy the first schedule words; there is no separate linked byte list. Internal fixed padding and schedule arithmetic are distinct from logical input-byte work.
- `cursors.c`, `core_cursor_bind_valid`: six source-owner U32 fields, one owned byte block plus its metadata, and the absolute window base are returned intact on both branches. A successful bind preserves the logical source owner separately from the physical byte allocation. No hidden clone is emitted here.
- `budget.c`, `core_budget_reserve_commit`: U32 run and serial, fixed six-dimension records and a bounded result/ticket representation; no array allocation is emitted in this constructor path. Type affinity is checked separately by positive/negative compiler controls. Flattened C values are not an API for user-created budgets or tokens.

The initial manual inspection used lines 11390/10793/10352 of roundtrip.c, 8018 of sha.c, 5863 of cursors.c and 1633 of budget.c. Fresh build records are authoritative if line positions change. Charge calibration uses real overlapping buffers, metadata and states, and must succeed independently; the inspection alone does not approve the candidate profile.
