The safe path is project-authored synthetic XML plus an independent XML oracle for implementation testing, with an explicit separate real-export gate. To clear that gate, capture intact XML from an identified xTranslator 1.6.0 binary using a project-owned minimal plugin, record producer/version/hash and export settings, hash the plugin and resulting XML, verify reuse permission, and run the same parser/oracle checks. Do not call regenerated, repaired, or hand-transcribed XML a real export.
